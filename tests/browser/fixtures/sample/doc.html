组件与报告模板示例

🧭 模板背景

这份页面集中展示 HTML Report Studio 已提供的阅读排版、图表、表格和折叠内容块。Agent 可以复制其中的局部结构，但应根据真实材料选择需要的部分，不把整套页面机械套用到每一份报告。

🧩 组件设计

  • 内容组件：基础 Markdown、KaTeX 公式、报告自己定义的图表、示意图和三种表格展示方式可以按材料组合。
  • 共享默认：颜色、间距、响应式、数字列排序和图表重画由共享组件统一处理。

📦 交付结果

Agent 先理解材料和组织结论，再选择能够准确表达关系的组件；最终产物是无需项目服务器即可直接打开的独立 HTML。

export function score(values: number[]): number {
  // 用平均值汇总本次结果
  if (values.length === 0) return 0;
  return values.reduce((sum, value) => sum + value, 0) / values.length;
}

阅读结构与辅助组件

报告默认使用 920px 居中的单一阅读边界。标题、正文、图表和表格容器共享同一对左右边界；列数少且内容短的普通表从左侧按内容宽度收拢，确实无法压缩的宽表在自身容器内横向滚动。普通说明使用正文段落，来源和范围使用 .doc-note。

使用边界：提示框是可选组件。只有需要明确风险、状态或关键口径时才使用。

示例数据集 Atlas-Bench 的名称可以直接作为详情卡片触发入口；需要独立操作入口时也可使用普通按钮。

行内公式与行间公式

行内公式嵌入句子，例如 \(\Delta = S_e - S_b\)，不会打断正文阅读。

按阅读任务选择模板

阅读任务优先模板使用条件
全文快速理解开头概括块零背景读者需要先看到项目用途、范围和最重要结果；正文稳定后再反写
连续阅读标题、正文、普通小节解释背景、口径、证据和结论
精确查值普通表格或超宽表源材料本身是行列结构，或读者需要同时比较多个值
交互排名普通数据表的自动排序纯数字列自动启用；文本或日期列按需显式启用
类别比较、有序变化自己的图表类型（DocCharts.define，数据写成 JSON）按数据的形状选画法：类别用条形，时间、步骤等有序类别用折线
精确排名自己的图表类型（DocCharts.define）数值接近时给出刻度，读者能读出差距
数据已在表格里从表格画的图（表格上写 data-doc-chart）表格和图读同一份数据，改表格时图随之重画
示意图、时间线、架构图卡片里的 HTML/SVG（figure.doc-figure）标题和说明写在卡片上，图里不再画一层外框
长 Case、问答或代码Details内容必须完整保留，但不需要默认全部展开
分布、地图、网络或复杂统计图自己的图表类型（用 D3 画）按数据的真实关系画

问题

某实验得分为 51.60，共同基线为 49.80。实验相对基线提升多少分？

标准答案

提升 1.80 分，计算为 51.60 − 49.80 = 1.80。

系统回答 A

实验相对基线提升 1.80 分。

系统回答 B

提升约 1.8%，因为 51.6 − 49.8 = 1.8。

问题说明

回答 B 的数值计算正确，但单位错误：这里比较的是两个分数的差值，应表述为“1.80 分”，不能直接写成百分比。

Atlas-Bench 详情

Atlas-Bench 是本组件页使用的演示名称。详情卡片沿用普通报告正文的排版和组件能力，具体内容由 Agent 根据材料与阅读任务决定。
